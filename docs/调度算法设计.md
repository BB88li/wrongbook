# 错题复习调度算法（定稿 v1）

> 2026-11-18
> 全文只有两条数学式子：一条遗忘曲线、一条修正公式，其余都是规则和表格。
> 这一版**取代**之前的两版设计（演进过程见文末），是后续实现与论文写作的唯一依据。
> **注意**：当前仓库里的 v0.2 代码实现的是简化版（SM-2 + 考试倒计时），本文描述的"记忆校准 + 状态判定 + 风险排序"计划在 2027-01 实现。

---

## 0. 三分钟读懂

**目标**：每天能复习的题有限，让"考试那天能想起来的题"尽量多。

**系统每天做四件事**：

1. 看每道题**还能记住多久**（记一个数 S）。
2. 按最近两次结果，判它是**不会 / 不稳定 / 已巩固**。
3. 算每道题**到考试前忘掉的概率**，乘上状态权重，得到分数。
4. 不会的题先去"重学"；其余的按分数排序，取前 B 道复习。

复习完，用实际结果**修正 S**——猜高了就调低，猜低了就调高。

---

## 1. 要解决什么问题

| 现有工具的问题 | 本系统怎么做 |
|---|---|
| SM-2 只按记忆强度排期，不看考试日期，容易排到考试之后 | 加考试日期：到期日被压缩到考前，最后 7 天每天过一遍 |
| "会了又忘"和"一直都会"被当成一样的 | 看最近两次结果，分成三种状态，分开处理 |
| "一直不会"的题反复复习也没用，但只按收益排序时会被放弃 | 单独走"重学通道"，固定排最前 |
| 每道题用同一个固定公式，不分个体 | 每道题有自己的 S，按实际表现校准 |

**一句话**：不是"按天提醒你复习"，而是"每天告诉你今天最该复习哪几道、为什么"。

---

## 2. 三个核心量

### 2.1 记忆强度 S

每道题记一个数 **S（天）**，含义是"大概能记住多少天"。

"现在还记得的概率"：

```
R = e^(-t/S)        t = 距上次复习过了几天
```

代入就懂：S = 10 时，隔 3 天还剩 74%，隔 7 天剩 50%，隔 10 天剩 37%。

**初始 S 按错因给**：

| 错因 | 初始 S | 理由 |
|---|---|---|
| 概念不清 | 3 天 | 根上没懂，忘得最快 |
| 方法不会 | 5 天 | 有印象但不会用 |
| 粗心 | 7 天 | 本来会，只是手滑 |

### 2.2 掌握状态

只看**最近两次**复习结果：最近一次答对记 2 分，上一次答对记 1 分，满分 3 分。

| 得分 | 状态 | 怎么处理 |
|---|---|---|
| 0（两次都错） | **不会** | 走重学通道：先看解析、重做，排在所有题之前，每天最多 5 道 |
| 1～2 | **不稳定** | 正常复习，权重 ×1.5 |
| 3（两次都对） | **已巩固** | 正常复习，权重 ×0.6 |

只复习过 0～1 次的题，按"不稳定"处理。

### 2.3 遗忘风险

**到考试那天，不复习的话会忘掉的概率**：

```
q = 1 - e^(-(考试日期 - 上次复习日期) / S)
```

- 昨天刚复习、考试还有 15 天、S = 5 → q = 1 - e^(-16/5) ≈ 0.96
- 同样条件下 S = 15 → q = 1 - e^(-16/15) ≈ 0.66

没有设置考试日期时，退化为"现在已经忘掉的概率"：`q = 1 - e^(-已过天数 / S)`。

## 3. 每天怎么排

```
score = q × 状态权重        （不稳定 1.5，已巩固 0.6）
```

**流程**：

```
每天：
  1. 到期题 = { R ≤ 0.5 的题 } ∪ { 考前必须排的题 }
  2. 不会的题 → 重学通道，按"概念 > 方法 > 粗心"排序，每天最多 5 道
  3. 其余 → 算 q，乘状态权重，得到 score
  4. 按 score 从高到低取前 B 道（B = 每日复习上限，默认 20）
  5. 每复习完一道：先猜、再看、再改 S；刷新状态和下次日期
```

**到期怎么算**：R ≤ 0.5 就到期的意思，也就是"隔了 0.7×S 天"。

**考试日期怎么起作用**：

1. 每道题的到期日不超过"考试前 3 天"——保证所有题考前至少排上一次；
2. 剩余 7 天进入考前模式，每天把到期的题过一遍，按 score 排序；
3. 风险 q 里的"距考试天数"，让越接近考试的题越优先。

**为什么用"风险"而不是"收益"**：

一开始想用"复习一次能提升多少回忆概率"当分数。但推演后发现它会偏向 S 大的题：会了又忘的题 S 已经被校准压小了，再怎么复习也提升不了多少，反而会被排到后面——和"假掌握要优先"的初衷矛盾。改成"到考试前会忘的概率"，就更符合直觉：**越可能忘、状态越差，越先复习**。

---

## 4. 记忆强度怎么更新（"智能"所在）

每次复习，三步：

1. **先猜**：用 `R = e^(-t/S)` 算出"这次你大概还记得多少"。
2. **再看**：实际是记得（1）还是忘了（0）。
3. **再改**：

```
S = S × (1 + 0.8 × (实际 - 猜测))
```

并把 S 限制在 1～60 天。

| 系统猜的 | 实际 | S 怎么变 |
|---|---|---|
| 80% 还记得 | 忘了 | 变成 0.36 倍，以后复习更密 |
| 30% 还记得 | 答对 | 涨 56%，间隔拉长 |
| 45% 还记得 | 答对 | 涨 44%，小幅拉长 |

**效果**：每道题的 S 都是被它自己"猜错"改出来的。答得越准，S 越大，下次隔得越久；老忘的题 S 上不去，复习越来越密。

> 这是"预测—对照—修正"的在线校准，比 SM-2 的固定公式多了一层"从错误里学"。也是论文里"智能"的第一处支撑。

## 5. 一道题走一遍

一道"概念不清"的题，初始 S = 3：

| 时间 | 隔了几天 | 系统猜你记得 | 实际 | S 变成 |
|---|---|---|---|---|
| 第 1 天 | 1 | 72% | 答对 | 3.7 |
| 第 4 天 | 3 | 44% | 答对 | 5.3 |
| 第 8 天 | 4 | 47% | **答错** | 3.3 |

三次之后：最近两次是"对、错"，得分 1 → **不稳定**，下次安排在 2 天后（0.7 × 3.3）。

## 6. 四道题一起排

考试还有 15 天，四道题都是 5 天前复习过、今天到期（所以"上次复习到考试"是 20 天），B = 3：

| 题 | 错因 | 历史 | 状态 | S | 风险 q | 权重 | 分数 | 顺序 |
|---|---|---|---|---|---|---|---|---|
| A | 概念 | 错、对 | 不稳定 | 5 | 0.98 | 1.5 | **1.47** | 2 |
| B | 方法 | 对、错 | 不稳定 | 7 | 0.94 | 1.5 | **1.41** | 3 |
| C | 粗心 | 对、对 | 已巩固 | 15 | 0.74 | 0.6 | **0.44** | 4 |
| D | 概念 | 错、错 | **不会** | 3 | — | — | 重学通道 | **1** |

今天的顺序：**D（重学）→ A → B → C**。

- D 两次都错，先看解析重做，不参与打分；
- A 是概念题、S 小、风险最高，排复习第一；
- C 已经巩固、S 大，风险低，排最后。

## 7. 参数表

| 参数 | 取值 | 含义 | 怎么定 |
|---|---|---|---|
| 初始 S（概念/方法/粗心） | 3 / 5 / 7 天 | 起跑线 | 经验值，用真实数据标定 |
| 校准系数 | 0.8 | 每次修正的力度 | 实验里试 0.5 / 0.8 / 1.0 |
| S 范围 | 1～60 天 | 防极端 | 经验值 |
| 到期阈值 | R ≤ 0.5 | 什么时候算"该复习" | 对应 0.7×S |
| 状态权重 | 不稳定 1.5 / 已巩固 0.6 | 状态的影响 | 实验里做敏感性分析 |
| 重学通道上限 | 5 道/天 | 防止难题占满 | 经验值 |
| 每日复习上限 B | 20 道 | 时间预算 | 设置页可改 |
| 考前模式 | 剩余 ≤7 天 | 每天过一遍 | 经验值 |
| 考前预留 | 3 天 | 最后缓冲 | 经验值 |

**只有 3 个参数是"拍"的**（校准系数、两个权重），实验里会做敏感性分析，论文里给出选择依据。其余都有明确含义。

## 8. 和 SM-2 / FSRS 的区别

| | SM-2（1987） | FSRS（2022） | 本系统 |
|---|---|---|---|
| 记忆模型 | 固定间隔表 + EF | 三参数 DSR | 单参数 S |
| 参数来源 | 公式硬编码 | 大量数据拟合 | 预测误差校准 |
| 看考试日期 | 否 | 否 | **是** |
| 有每日预算 | 否 | 否 | **是** |
| 区分不会 / 会了又忘 | 否 | 部分 | **是** |
| 数据需求 | 无 | 上百条 | 2～5 条即可 |

**为什么不用 FSRS**：它需要大量复习记录拟合三个参数，单人一个月的 20～50 道题远远不够；而且它的目标是"长期保持记忆"，不含考试日期和每日预算。单参数模型 + 在线校准，是在数据量约束下的合理选择——这一点会在论文"局限性"里写明。

## 9. 错因怎么用（不进入权重）

错因**不乘进分数**，理由三条：

1. **已经生效**：初始 S 就是按错因给的，概念题复习频率天然是粗心题的 2 倍多。
2. **避免重复计算**：再乘一个"概念 ×1.2"，等于把"概念题忘得快"算了两遍；答辩时"为什么是 1.2"也答不上来。
3. **错因是主观标签**：学生自己选，可能选错，不适合当强因子。

错因该起作用的地方是另外两处：

- **重学通道内部排序**：都是"不会"的题，先重学概念，再方法，最后粗心。
- **复习方式**（1 月做）：概念题先看解析；方法题提示"有没有更通用的解法"；粗心题提示"上次错在符号/计算"。

如果老师希望有显式的"错因系数"，就做成开关，在第 6 章跑两组对比，用实验决定。

## 10. 怎么证明有用

**数据**：模拟器（200 题，带真实记忆参数和噪声）+ 本人 12 月的真实使用记录（20～50 题）。

**对照组**：固定间隔 / 艾宾浩斯表 / 原版 SM-2 / 本系统。

**指标**：考前回忆率、复习次数、考前覆盖率、预测误差（Brier）。

**消融**（证明每块都有用）：

| 去掉什么 | 预期 |
|---|---|
| 去掉 S 校准（S 固定） | 考前回忆率下降 |
| 去掉状态判定（全部按风险排） | "不会"的题被淹没 |
| 去掉考试约束 | 有题排到考试之后 |
| 去掉重学通道 | 反复不会的题空耗复习次数 |

**说明**：模拟器是简化假设，论文里要写清楚，不能当成真实用户结论；真实数据只做案例分析。

## 11. 答辩可能被问到的问题

**Q：为什么用 e^(-t/S)？**
A：这是心理学最经典的遗忘曲线形式，一个参数就能描述"越久越容易忘"，而且 e 在考研数学里天天见。更精确的曲线需要更多数据拟合，单人数据量不够，这一点写在局限性里。

**Q：哪里体现了"智能"？**
A：四件事——每道题的 S 由预测误差自动校准；按最近两次判状态；按遗忘风险排序；把考试日期变成约束。不是套一个固定公式。

**Q：和 Anki 有什么区别？**
A：Anki 按记忆强度排期，不看考试日期，也不区分"不会"和"会了又忘"；本系统加了考试约束、状态通道和风险排序。

**Q：参数怎么定的？**
A：初始 S 和权重是经验值，实验里做敏感性分析（0.5/0.8/1.0、1.2/1.5/1.8），论文给出选择依据。

**Q：怎么证明比 SM-2 好？**
A：模拟器上跑四种策略对比，再对四个模块做消融；真实数据做案例补充。

**Q：只用了一个参数，会不会太简单？**
A：单参数是为了在 20～50 道题的数据量下还能稳定估计；复杂模型（FSRS）需要上百条记录才能拟合，我们不具备这个条件。简单不等于不成立，关键是每部分都能解释、能验证。

## 附录：演进记录（可写进"方案迭代"）

1. **第一版**：SM-2 + 考试倒计时截断。问题：失败不清零、间隔无上限，已修。
2. **第二版**：加"重点程度权重"（巩固度/反复度/不确定度加权）。问题：连续三次不会的题权重反而低于"会了又忘"，顺序反了。
3. **第三版**：改成状态判定 + 重学/复习双通道。问题：用"复习收益 Δ"排序时，S 小的题收益也小，会被优化器放弃。
4. **定稿**：把"收益"换成"风险"，S 小的题风险高、自然优先；同时保留状态权重和重学通道。

这段演进本身就是论文里"设计如何被检验和修正"的素材，答辩时讲它比只讲最终公式更有说服力。
