# 智能复习调度：定义、算法与验证

> 2026-11-18 · 回应导师意见「解释清楚智能复习调度」
> **结论先行**：当前 v0.2 实现的是「规则版自适应调度」（SM-2 + 考试倒计时约束），还不足以支撑题目里的「智能」。要撑起来需要补齐三件事：**可学习的记忆参数、可优化的调度决策、可验证的实验**。本文给出定义、算法设计与验证方案。

---

## 0. 一分钟回答

> 系统为每道错题维护一条**可以被数据修正的遗忘曲线**：每次复习的结果都用来更新这道题的"记忆稳定度"；每天在"距离考试还有几天"和"今天最多复习几道"的约束下，计算每道题**复习一次能让考试当天的回忆概率提升多少**，优先复习提升最大的题。智能体现在三处——**参数是学出来的**（不是所有题共用一个公式）、**决策是算出来的**（不是只看到期日）、**效果是可验证的**（能预测回忆概率并计算误差）。

这段可以直接放进论文 1.3 节或答辩开场。

## 1. 先划清边界："智能"在这里指什么

智能复习调度 = **在有限时间与考试截止日期的约束下，依据学习者的历史反馈，自动决定"今天复习哪些题、下次什么时候再复习"，使考试当天的回忆成功率最大化。**

拆成四个能力，逐项对照现状：

| 能力 | 含义 | 现状 v0.2 | 目标 |
|---|---|---|---|
| **感知** | 系统知道什么 | 到期日、错因、复习次数、掌握度、考试日期 | 增加：每题的记忆稳定度 S、历史回忆曲线 |
| **决策** | 每天做什么 | 固定公式算间隔 + 加权排序 | 期望收益最大化（预算约束下的排序） |
| **学习** | 会不会从数据里改自己 | SM-2 的 EF 按固定公式加减 | 从复习流水估计每题的 S（经验贝叶斯） |
| **评估** | 知不知道自己准不准 | 无 | 预测回忆概率，计算 Brier 分数与校准曲线 |

**一条自检标准**：如果把"学习"和"决策优化"两部分删掉，系统还能不能跑？能——那就退化成了一张固定间隔表，这时候叫"智能"是站不住的。这正是接下来要补的部分。

> 需要说明的是：这里的"智能"不是深度学习，而是**数据驱动的自适应调度**。本科阶段这样定义是合理且可辩护的：方法可解释、可复现、可评估，比套一个黑箱模型更适合这个题目。

## 2. 把调度问题形式化

- 题库 $I$，第 $i$ 题在时刻 $t$ 的可回忆概率：$R_i(t) = \exp\left(-\dfrac{t - t_i^{last}}{S_i}\right)$
- 考试日期 $T$，今天 $d$，每天最多复习 $B$ 题（时间预算）
- 决策变量：今天复习的题目集合 $A_d \subseteq \text{Due}_d$，$|A_d| \le B$
- 目标：$\max \sum_{i \in I} R_i(T)$ —— 让考试当天"能想起来的题数"的期望最大

这是一个**有限时域、带预算的序贯决策问题**：今天复习哪几道，会改变这些题在 $T$ 时刻的记忆状态，而未来的复习机会有限。精确求解需要预知未来的反馈，因此采用贪心近似。

**这个问题定义本身就是一个贡献点**：SM-2 与 Anki 优化的是"间隔规则"，本系统优化的是"考试当天的回忆期望"，目标函数不同，调度结果自然不同。

---

## 3. 算法设计

### 3.1 记忆模型

采用单参数指数遗忘模型：

$$R_i(t) = \exp\left(-\frac{t - t_i^{last}}{S_i}\right)$$

- $S_i$：记忆稳定度，物理含义是"回忆概率衰减到 37% 所需的天数"，越大越不容易忘；
- 初始值按错因给定：粗心 3 天 / 方法 2 天 / 概念 1.5 天（初始值需用数据标定，见 3.4）。

> 为什么不用 FSRS？FSRS 需要上百条复习记录才能拟合三个参数，单人一个月的 20–50 道题远远不够；且 FSRS 的目标是"长期保持记忆"，不含考试日期与每日预算。这里选择单参数模型 + 先验，是在数据量约束下的合理简化。

### 3.2 参数学习（"智能"的第一处体现）

对第 $i$ 题，历史上有若干次复习：相隔 $\Delta t_j$ 天后回忆结果为 $y_j \in \{0,1\}$。似然：

$$L_i(S) = \prod_j R(\Delta t_j; S)^{y_j}\,\bigl[1 - R(\Delta t_j; S)\bigr]^{1-y_j}$$

因为单题观测只有 2–5 条，直接做极大似然会过拟合，所以引入**按错因分组的先验**（经验贝叶斯 / 分层先验）：

$$\hat{S}_i = \arg\max_S \left[\log L_i(S) + \lambda \log p(S \mid \mu_{g(i)}, \sigma)\right]$$

- $g(i)$ 是错因分组，$\mu_g$ 是该组的稳定度均值；
- 先验取对数正态，$\sigma$ 控制收缩强度；
- 求解：在离散网格（0.5, 1, 2, …, 365 天）上搜索，坐标上升 2–3 轮估计 $\mu_g$；
- 冷启动：观测少于 2 条时直接用 $\mu_g$。

**效果**：同一错因下，记得牢的题 $S$ 大、间隔自然拉长；反复忘的题 $S$ 小、复习更密。这就是"个体化"——而不是所有题共用 EF=2.5。

### 3.3 决策（"智能"的第二处体现）

复习第 $i$ 题带来的边际收益：

$$\Delta_i = R_i^{after}(T) - R_i^{before}(T)$$

- $R^{before}$：不做这次复习，考试当天的回忆概率；
- $R^{after}$：复习后 $S_i$ 更新、上次复习时间变为今天，考试当天的回忆概率；
- 单位成本 $c_i$（默认 1，可按题目长度或难度加权）。

按 $\Delta_i / c_i$ 降序取前 $B$ 道，这是一个**贪心背包**——在预算约束下近似最大化目标函数。

> 为什么它比"到期日排序"更聪明：到期日只知道"该复习了"，而 $\Delta_i$ 同时回答三个问题——这题离考试还有多久、我有多可能已经忘了、复习一次能挽回多少。一道刚复习过、考前也不会忘的题，即便到期，$\Delta_i$ 也很小，会被排到后面。

### 3.4 考试日期怎么进入模型

两种方式，**软约束为主、硬约束兜底**：

1. **软约束**：$T$ 直接出现在目标函数与 $\Delta_i$ 里。离考试越近，同样的复习带来的 $R(T)$ 提升越大；离考试很远的题，今天复习的收益会被后续遗忘抵消，自然排到后面。
2. **硬约束**：保证每道题在 $T$ 之前至少被复习一次——若剩余天数已不足以按自然间隔排完，则压缩间隔（这就是 v0.2 已有的倒计时截断逻辑，作为兜底保留）。

### 3.5 伪代码

```
每天 d：
  due ← { i | R_i(d) < θ } ∪ { i | 硬约束要求今天复习 }
  for i in due:
      Δ_i ← R_i^after(T) - R_i^before(T)
  A ← 按 Δ_i / c_i 排序，取前 B 道
  for i in A:
      展示题目 → 学生自评 → 记录 (Δt, y)
      用 3.2 更新 S_i
```

复杂度 $O(|\text{Due}| \cdot B)$，50 题规模可忽略。

### 3.6 与 SM-2 / FSRS 的定位

| | SM-2（1987） | FSRS（2022） | 本系统 |
|---|---|---|---|
| 记忆模型 | 固定间隔表 + EF | 三参数 DSR | 单参数 S + 错因先验 |
| 参数来源 | 公式硬编码 | 大规模数据拟合 | 单题历史 + 分层先验 |
| 是否考虑考试 | 否 | 否 | **是** |
| 是否有预算 | 否 | 否 | **是** |
| 数据需求 | 无 | 上百条记录 | 2–5 条即可起步（靠先验） |

## 4. "智能"体现在哪：机制与代码对照

| 能力 | 机制 | 目标文件 | 可观测输出 |
|---|---|---|---|
| 感知 | 记录每次复习的间隔与结果 | `models/review.py`（已实现） | `review_logs` 流水 |
| 学习 | 经验贝叶斯估计每题 $S_i$ | `services/memory.py`（待新增） | 每题的 $S_i$、预测 $R$ |
| 决策 | 期望收益贪心排序 | `services/scheduler.py`（待新增） | 今日列表 + 每题的 $\Delta_i$ |
| 约束 | 考试截止 + 每日预算 | 同上 | 考前覆盖率 |
| 评估 | 预测校准与策略对比 | `scripts/` + 实验脚本 | Brier 分数、考前回忆率 |

前端可以顺带展示"为什么今天复习这道题"（$\Delta_i$ 与掌握度），这既是产品功能，也是答辩演示时最直观的"智能"证据。

## 5. 怎么证明有用

### 5.1 数据来源

1. **真实数据**：本人 2026-12 冲刺期使用，预计 20–50 道题、数百条复习流水。样本小，只做案例分析与参数标定，不做显著性结论。
2. **模拟器**：生成 200 道题，每道题有隐藏的真实稳定度 $S_i^*$ 与难度，按模型产生复习结果（含噪声与模型错配），用于对比不同策略。

### 5.2 对照组

- 固定间隔（1/3/7/15 天）
- 艾宾浩斯间隔表
- SM-2（v0.2 现有实现）
- 本系统完整版

### 5.3 指标

| 指标 | 含义 |
|---|---|
| 考前回忆率 | 考试当天模拟的"能想起来"的比例（核心指标） |
| 复习次数 | 达到相同效果付出的成本 |
| 考前覆盖率 | 考试前所有题至少复习 N 次的比例 |
| Brier 分数 | 预测回忆概率的校准误差，越低越好 |
| 间隔预测 MAE | 预测的遗忘时间与实际偏差 |

### 5.4 消融实验（证明每部分是必要的）

| 变体 | 去掉什么 | 预期结果 |
|---|---|---|
| 无学习 | 用组均值 $\mu_g$ 代替每题 $S_i$ | 考前回忆率下降 |
| 无考试项 | $T \to \infty$ | 考前覆盖率下降 |
| 无错因先验 | 所有题共用一个 $\mu$ | 冷启动阶段表现变差 |
| 无预算 | 每天复习全部到期题 | 复习次数上升，收益递减 |

### 5.5 结果呈现

一张"策略 × 指标"表 + 一张随天数变化的折线图 + 一张消融柱状图。**具体数值等实验跑完再填，现在不预设结论。**

> 学术诚信：模拟器是对记忆过程的简化假设，论文中必须写明假设与局限，不能包装成真实用户实验结论。
