# 智能复习调度：定义、算法与验证

> 2026-11-18 · 回应导师意见「解释清楚智能复习调度」
> **结论先行**：当前 v0.2 实现的是「规则版自适应调度」（SM-2 + 考试倒计时约束），还不足以支撑题目里的「智能」。要撑起来需要补齐三件事：**会自我校准的记忆参数、会分状态的调度决策、可验证的实验**。本文给出定义、算法设计与验证方案。

---

## 0. 一分钟回答

> 系统为每道错题维护一条**可以被数据修正的遗忘曲线**：每次复习的结果都用来更新这道题的"记忆稳定度"；同时根据复习序列把每道题判为**不会 / 不稳定 / 已巩固**三类，不会的题先进重学通道；每天在"距离考试还有几天"和"今天最多复习几道"的约束下，计算每道题**复习一次能让考试当天的回忆概率提升多少**，优先复习提升最大的题。智能体现在四处——**参数是学出来的、状态是判出来的、决策是算出来的、效果是可验证的**。

这段可以直接放进论文 1.3 节或答辩开场。

## 1. 先划清边界："智能"在这里指什么

智能复习调度 = **在有限时间与考试截止日期的约束下，依据学习者的历史反馈，自动决定"今天复习哪些题、下次什么时候再复习"，使考试当天的回忆成功率最大化。**

拆成四个能力，逐项对照现状：

| 能力 | 含义 | 现状 v0.2 | 目标 |
|---|---|---|---|
| **感知** | 系统知道什么 | 到期日、错因、复习次数、掌握度、考试日期 | 增加：每题的记忆稳定度 S、历史回忆曲线 |
| **决策** | 每天做什么 | 固定公式算间隔 + 加权排序 | 期望收益最大化（预算约束下的排序） |
| **学习** | 会不会从数据里改自己 | SM-2 的 EF 按固定公式加减 | 先预测、再按实际结果修正每题的 S |
| **评估** | 知不知道自己准不准 | 无 | 预测回忆概率，计算 Brier 分数与校准曲线 |

**一条自检标准**：如果把"学习"和"决策优化"两部分删掉，系统还能不能跑？能——那就退化成了一张固定间隔表，这时候叫"智能"是站不住的。这正是接下来要补的部分。

> 需要说明的是：这里的"智能"不是深度学习，而是**数据驱动的自适应调度**。本科阶段这样定义是合理且可辩护的：方法可解释、可复现、可评估，比套一个黑箱模型更适合这个题目。

## 2. 把调度问题形式化

- 题库 $I$，第 $i$ 题在时刻 $t$ 的可回忆概率：$R_i(t) = \exp\left(-\dfrac{t - t_i^{last}}{S_i}\right)$
- 考试日期 $T$，今天 $d$，每天最多复习 $B$ 题（时间预算）
- 决策变量：今天复习的题目集合 $A_d \subseteq \text{Due}_d$，$|A_d| \le B$
- 目标：$\max \sum_{i \in I} R_i(T)$ —— 让考试当天"能想起来的题数"的期望最大

这是一个**有限时域、带预算的序贯决策问题**：今天复习哪几道，会改变这些题在 $T$ 时刻的记忆状态，而未来的复习机会有限。精确求解需要预知未来的反馈，因此采用贪心近似。

**这个问题定义本身就是一个贡献点**：SM-2 与 Anki 优化的是"间隔规则"，本系统优化的是"考试当天的回忆期望"，目标函数不同，调度结果自然不同。

## 3. 算法设计

### 3.0 先用一道题走一遍

一道"概念不清"的错题，初始 S = 3 天：

| 日期 | 隔了几天 | 系统猜你记得 | 你的结果 | 系统怎么改 |
|---|---|---|---|---|
| 第 1 天 | 1 天 | 72% | 答对 | 猜低了 → S 从 3 调到 3.7 |
| 第 4 天 | 3 天 | 44% | 答对 | 猜低了 → S 从 3.7 调到 5.3 |
| 第 8 天 | 4 天 | 47% | **答错** | 猜高了 → S 从 5.3 砍到 3.3 |

三次复习之后：这道题被标成"不稳定"（最近两次是"对、错"），下次复习安排在 2 天后——比上次更密。

整个过程只有加、减、乘、除，没有积分、没有概率分布。

### 3.1 记忆模型：一道题只记一个数

每道题维护一个数 **S（记忆强度，单位：天）**，含义是"大概能记住多少天"。

"现在还记不记得"按指数衰减估算：

$$R = e^{-t/S}$$

- $t$：距上次复习过了几天；
- $S$：这道题的记忆强度。

代入数字就很好懂：S = 10 时，隔 3 天还剩约 74%，隔 7 天剩 50%，隔 10 天剩 37%。

初始 S 按错因给：粗心 7 天 / 方法不会 5 天 / 概念不清 3 天——概念性的题忘得最快。

> 为什么用 $e^{-t/S}$ 而不是更复杂的模型：这是心理学里最经典的遗忘曲线形式，一个参数就能描述"越久越容易忘"，而且 $e$ 在考研数学里天天见。真正复杂的是数据拟合，那部分我们不做（见 3.2 的说明）。

### 3.2 记忆强度怎么改：先猜、再对、再改（"智能"的第一处体现）

每次复习，系统只做三步：

1. **先猜**：用上面的公式算出"这次你大概还记得多少"。比如 S = 5、隔了 4 天，猜 45%。
2. **再看**：你实际是"记得"（记 1）还是"忘了"（记 0）。
3. **再改**：猜得不准，就按误差修正：

$$S \leftarrow S \times \bigl[1 + 0.8 \times (\text{实际} - \text{猜测})\bigr]$$

并限制在 1～60 天之间。

三种情况一眼能看懂：

| 系统猜的 | 实际结果 | S 怎么变 | 后果 |
|---|---|---|---|
| 猜 80% 还记得 | 忘了 | 变成 0.36 倍 | 以后复习更密 |
| 猜 30% 还记得 | 答对 | 涨 56% | 间隔拉长 |
| 猜 45% 还记得 | 答对 | 涨 44% | 间隔小幅拉长 |

**这就是"智能"的第一处体现**：系统不是套一个固定公式，而是**先预测、再用实际结果校准**。每道题的 S 都是被它自己的"猜错"改出来的：答得越准，S 越大，下次隔得越久；老忘的题 S 一直上不去，复习越来越密。

> 只有 0.8 一个系数，含义是"修正力度"。1 月做实验时会分别用 0.5 / 0.8 / 1.0 跑一遍，看哪个效果最好，论文里给出选择依据。
>
> **为什么不做极大似然估计或贝叶斯先验**：单题只有 2–5 条记录，拟合出来的参数不稳，而且要写一大堆公式。用"预测误差修正"得到的效果接近，但每一步都能用一句话解释清楚。这是有意的简化，论文"局限性"里会写明。

### 3.3 掌握状态判定：区分"不会""假掌握""已巩固"（"智能"的第二处体现）

只看遗忘概率不够，因为三种历史的含义完全不同：

| 历史复习结果 | 真实含义 | 处理方式 |
|---|---|---|
| 忘、忘、忘 | 知识缺口，不是"忘了"，是"不会" | 重学：先看解析、重做，优先级最高 |
| 会、忘 | 第一次的"会"可能是再认或蒙对 | 复习，高优先级 |
| 会、会、会 | 真正巩固 | 复习，低优先级 |

关键区分：**"一直不会"和"会了又忘"不是同一类问题**。前者缺的是知识，需要重学；后者缺的是巩固，需要复习。如果用同一个权重把两者相加，必然顾此失彼——第一版公式就犯了这个错：连续三次不会只得 1.0，反而低于"会了又忘"的 1.9。

更麻烦的是：如果完全按"复习带来的考前回忆概率提升 $\Delta$"排序，反复不会的题复习一次提升也小，优化器会**放弃它们**——而这类题恰恰最该投入时间。所以必须把它们单独拎出来，不参与常规的收益排序。

#### 状态判定：只看最近两次

规则很简单：**最近一次答对记 2 分，上一次答对记 1 分，满分 3 分**。

1. 0 分（最近两次都错）→ **未掌握**
2. 1～2 分 → **不稳定**
3. 3 分（最近两次都对）→ **已巩固**

只复习过 0～1 次的题，按"不稳定"处理。

| 历史 | 最近两次 | 得分 | 状态 | 优先级 |
|---|---|---|---|---|
| 忘、忘、忘 | 错、错 | 0 | 未掌握 | **最高（重学）** |
| 会、忘 | 对、错 | 1 | 不稳定 | 高 |
| 忘、会 | 错、对 | 2 | 不稳定（上升期） | 中 |
| 会、会、会 | 对、对 | 3 | 已巩固 | 低 |

#### 处理策略

- **未掌握**：进入"重学通道"，排在当日所有复习题之前，每日最多 $M=5$ 道；展示时强制先给解析，学生重做后再自评。
- **不稳定**：走正常复习，权重 $w=1.5$。
- **已巩固**：走正常复习，权重 $w=0.6$。

这样"连续三次不会"一定排在第一位，而且不会因为 $\Delta$ 很小被优化器丢掉。

**这就是"智能"的第二处体现**：系统不是数"复习了几次"，而是判断这道题处在哪个学习阶段，再决定是"重学"还是"复习"。状态只由复习序列判定，不需要学生额外标注。

> **设计演进（写进论文的"方案迭代"）**：第一版把三种情况压成一个权重 $w = 1+0.6F+0.3U-0.4C$，结果连续三次不会的题拿到 1.0，低于"会了又忘"的 1.9，顺序反了。这说明"掌握状态"和"复习收益"是两个维度，不能用一个加权和硬凑。修正后改为状态判定 + 分通道处理。答辩时讲这一段，比只讲最终公式更有说服力。

### 3.4 决策：期望收益 × 状态权重，用贪心背包求解

对"不稳定"与"已巩固"的题（"未掌握"的题走 3.3 的重学通道，不参与本节排序），复习第 $i$ 题带来的边际收益：

$$\Delta_i = R_i^{after}(T) - R_i^{before}(T)$$

- $R^{before}$：不做这次复习，考试当天的回忆概率；
- $R^{after}$：复习后 $S_i$ 更新、上次复习时间变为今天，考试当天的回忆概率；
- 单位成本 $c_i$（默认 1，可按题干长度或难度加权）。

**综合优先级**：

$$score_i = \frac{\Delta_i \cdot w_i}{c_i}$$

其中 $w_i$ 由 3.3 的状态给出（不稳定 1.5，已巩固 0.6）。按 $score_i$ 降序取前 $B$ 道，即每天"最值得复习"的题。

#### 为什么是背包、为什么用贪心

把问题写成 0/1 背包：

- **价值** = $\Delta_i \cdot w_i$（复习这道题能挽回多少考前回忆概率）
- **重量** = $c_i$（复习成本）
- **容量** = $B$（每天最多复习几道）
- **目标** = 总价值最大

求解用贪心，理由可以正面回答：

1. 当所有题成本相同时，按价值排序取前 $B$ 就是**精确最优解**（等重背包退化为排序问题）；
2. 成本不同时，按"价值密度"$score_i$ 排序是**分数背包的最优解**、0/1 背包的近似解，误差上界不超过单件物品的最大价值；
3. 本题规模下（到期题几十道、$B \le 20$）贪心与动态规划的差距可以忽略，而贪心能对每一道题给出"为什么排在前面"的解释，答辩时讲得清楚。

复杂度 $O(n\log n)$。若需要精确解，也可用 $O(nB)$ 的动态规划，但收益需要离散化，解释性反而下降。

> 为什么它比"到期日排序"更聪明：到期日只知道"该复习了"，而 $score_i$ 同时回答四个问题——离考试还有多久、我有多可能已经忘了、复习一次能挽回多少、这道题处在哪个学习阶段。一道刚复习过、考前也不会忘的题，即便到期，分数也很低，会被排到后面。

### 3.5 考试日期怎么进入模型

两种方式，**软约束为主、硬约束兜底**：

1. **软约束**：$T$ 直接出现在目标函数与 $\Delta_i$ 里。离考试越近，同样的复习带来的 $R(T)$ 提升越大；离考试很远的题，今天复习的收益会被后续遗忘抵消，自然排到后面。
2. **硬约束**：保证每道题在 $T$ 之前至少被复习一次——若剩余天数已不足以按自然间隔排完，则压缩间隔（这就是 v0.2 已有的倒计时截断逻辑，作为兜底保留）。

### 3.6 伪代码

```
每天 d：
  due ← { i | R_i(d) < θ } ∪ { i | 硬约束要求今天复习 }

  # 第一通道：重学（未掌握的题）
  relearn ← [ i ∈ due | 状态_i = 未掌握 ]，按失败连击降序，取前 M 道
  for i in relearn:
      先展示解析 → 学生重做 → 自评 → 记录 (Δt, y)
      用 3.2 更新 S_i，刷新状态

  # 第二通道：复习（不稳定 / 已巩固）
  review ← due \ relearn
  for i in review:
      Δ_i ← R_i^after(T) - R_i^before(T)
      w_i ← 1.5（不稳定）或 0.6（已巩固）
      score_i ← Δ_i · w_i / c_i
  A ← 按 score_i 取前 B 道
  for i in A:
      展示题目 → 学生自评 → 记录 (Δt, y)
      用 3.2 更新 S_i，刷新状态
```

复杂度 $O(n\log n)$，50 题规模可忽略。重学通道的日上限 $M$ 防止"怎么都学不会"的题占满整天。

### 3.7 与 SM-2 / FSRS 的定位

| | SM-2（1987） | FSRS（2022） | 本系统 |
|---|---|---|---|
| 记忆模型 | 固定间隔表 + EF | 三参数 DSR | 单参数 S + 错因初始值 |
| 参数来源 | 公式硬编码 | 大规模数据拟合 | 单题历史 + 预测误差修正 |
| 是否考虑考试 | 否 | 否 | **是** |
| 是否有预算 | 否 | 否 | **是** |
| 是否识别"假掌握" | 否（只看上次对错） | 部分（难度更新） | **是（序列判定）** |
| 是否区分"不会/会了又忘" | 否 | 否 | **是（分通道处理）** |
| 数据需求 | 无 | 上百条记录 | 2–5 条即可起步（靠初始值） |

## 4. "智能"体现在哪：机制与代码对照

| 能力 | 机制 | 目标文件 | 可观测输出 |
|---|---|---|---|
| 感知 | 记录每次复习的间隔与结果 | `models/review.py`（已实现） | `review_logs` 流水 |
| 校准 | 先预测、再按实际结果修正 $S_i$ | `services/memory.py`（待新增） | 每题的 $S_i$ 与预测值 |
| 掌握状态 | 复习序列判定"不会 / 不稳定 / 已巩固" | `services/mastery.py`（待新增） | 每题的状态与判定依据 |
| 决策 | 期望收益 × 状态权重，贪心背包 | `services/scheduler.py`（待新增） | 重学队列 + 复习队列 |
| 约束 | 考试截止 + 每日预算 | 同上 | 考前覆盖率 |
| 评估 | 预测校准与策略对比 | `scripts/` + 实验脚本 | Brier 分数、考前回忆率 |

前端可以顺带展示"为什么今天复习这道题"（$\Delta_i$ 与掌握度），这既是产品功能，也是答辩演示时最直观的"智能"证据。

## 5. 怎么证明有用

### 5.1 数据来源

1. **真实数据**：本人 2026-12 冲刺期使用，预计 20–50 道题、数百条复习流水。样本小，只做案例分析与参数标定，不做显著性结论。
2. **模拟器**：生成 200 道题，每道题有隐藏的真实稳定度 $S_i^*$ 与难度，按模型产生复习结果（含噪声与模型错配），用于对比不同策略。

### 5.2 对照组

- 固定间隔（1/3/7/15 天）
- 艾宾浩斯间隔表
- SM-2（v0.2 现有实现）
- 本系统完整版

### 5.3 指标

| 指标 | 含义 |
|---|---|
| 考前回忆率 | 考试当天模拟的"能想起来"的比例（核心指标） |
| 复习次数 | 达到相同效果付出的成本 |
| 考前覆盖率 | 考试前所有题至少复习 N 次的比例 |
| Brier 分数 | 预测回忆概率的校准误差，越低越好 |
| 间隔预测 MAE | 预测的遗忘时间与实际偏差 |

### 5.4 消融实验（证明每部分是必要的）

| 变体 | 去掉什么 | 预期结果 |
|---|---|---|
| 无学习 | 用组均值 $\mu_g$ 代替每题 $S_i$ | 考前回忆率下降 |
| 无状态判定 | 所有题统一按 $\Delta$ 排序、不分通道 | "一直不会"的题被优化器放弃，考前回忆率下降 |
| 无考试项 | $T \to \infty$ | 考前覆盖率下降 |
| 无错因初始值 | 所有题用同一个 S0 | 冷启动阶段表现变差 |
| 无预算 | 每天复习全部到期题 | 复习次数上升，收益递减 |

### 5.5 结果呈现

一张"策略 × 指标"表 + 一张随天数变化的折线图 + 一张消融柱状图。**具体数值等实验跑完再填，现在不预设结论。**

> 学术诚信：模拟器是对记忆过程的简化假设，论文中必须写明假设与局限，不能包装成真实用户实验结论。

## 9. 给老师的三句话

1. 目前 v0.2 是"规则版"：SM-2 加考试倒计时，能跑通但还不能叫智能。
